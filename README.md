# 基于自监督图对比学习的剪力墙与柱分类 (GCL-Wall-Column)

## 📖 项目简介

本项目是一个基于 **自监督图对比学习 (Self-Supervised Graph Contrastive Learning)** 的示例程序。

原项目旨在演示如何区分几何形状（三角形 vs 矩形）。本项目在此基础上进行了针对性修改，应用于**建筑结构设计**领域，旨在通过图神经网络自动区分 **柱（Column）** 与 **剪力墙（Shear Wall）**。

## 🏗️ 背景与任务定义

在中国建筑结构设计规范（如《高层建筑混凝土结构技术规程》 JGJ 3-2010）中，对构件的定义存在明确的几何判定标准：

- **柱**：截面长宽比 $\le 4$
- **剪力墙**：截面长宽比 $> 4$

本项目通过生成不同长宽比的矩形图数据进行训练，试图让模型学习并根据这一几何特征进行二分类判别。

## ⚠️ 核心问题探讨：深度学习模型特性 vs 工程规范硬性指标

**（Current Limitation & Analysis）**

目前模型在绝大多数样本上表现优异，但在长宽比 **3.8 ~ 4.2** 的临界区间内，预测准确率出现显著下降。这一现象反映了深度学习在处理工程规范类任务时的一个典型矛盾。

### 1. 冲突本质
*   **工程规范（硬性指标）**：规范规定“4”是一个绝对的**离散阈值（Hard Threshold）**。3.99 是柱，4.01 是墙，二者在标签上是截然对立的（0 和 1）。
*   **深度学习（平滑流形）**：神经网络本质上是学习高维特征空间中的连续概率分布。在模型看来，长宽比 3.99 和 4.01 的矩形在几何特征上极度相似，属于特征空间中的紧密邻居。

### 2. 表现分析
模型难以在特征极其相似的情况下，强行拟合出一个类似阶跃函数（Step Function）的垂直决策边界。相反，模型倾向于学习出一条平滑的过渡曲线（如 Sigmoid），导致在 **4.0 附近的临界区域（如 3.8~4.2）**，模型的输出往往表现为“犹豫不决”（预测概率在 0.5 左右徘徊），从而导致分类准确率下降。

### 3. 结论
这表明直接使用离散分类任务（Classification）来解决基于连续数值阈值的工程判定问题，在临界点附近存在天然的理论瓶颈。对于实际工程应用，这一“模糊地带”需要通过后续的变通方案（如改为回归任务、引入人工复核区等）来解决，而非单纯依赖增加分类模型的训练量。

## 🚀 快速开始

### 依赖环境
*   Python 3.x
*   PyTorch
*   PyTorch Geometric (PyG)
*   NetworkX
*   Matplotlib (用于可视化)

### 运行代码
生成数据并开始训练：

```bash
# 请确保处于 v2.2自监督图对比学习墙柱 分支
python main.py
```

## 📂 项目结构

*   `main.py`: 主程序入口，包含模型训练与验证逻辑。
*   `dataset/`: 数据生成模块，负责生成不同长宽比的矩形图结构数据。
*   `model/`: 图神经网络（GNN）及对比学习模型定义。

## 🔮 未来改进方向

针对上述临界值识别困难的问题，未来计划尝试以下优化方案：

1.  **任务重构**：将“分类任务”改为“回归任务”，直接预测长宽比数值，再通过逻辑代码判断 $>4$，以符合神经网络拟合连续函数的特性。
2.  **难例挖掘 (Hard Example Mining)**：在训练集中大幅增加 3.9~4.1 之间的样本权重，强迫模型关注微小特征差异。
3.  **灰度机制**：在推理阶段引入置信度阈值，对于 3.8~4.2 范围内的预测结果标记为“待人工复核”，而非直接输出分类结果。
